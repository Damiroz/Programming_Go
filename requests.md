# Тестовые запросы для PZ3

## Обязательная часть

1. **GET /health** - проверка работы сервера
2. **POST /tasks** - создание задачи
3. **GET /tasks** - получение списка задач
4. **GET /tasks?q=фильтр** - фильтрация задач
5. **GET /tasks/{id}** - получение одной задачи
6. **POST без title** - ошибка 400
7. **POST неверный Content-Type** - ошибка 400
8. **GET несуществующий ID** - ошибка 404

Все запросы возвращают корректные коды статуса и JSON-ответы.
